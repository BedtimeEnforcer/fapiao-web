# 数据、设置与发行包

## 什么进入发行包

`packaging/报销助手.spec` 明确列出代码、网页、地图和机场目录。不收集发票原件、`data/`、上传文件、报告、测试样本、浏览器用户目录或日志。公开源码也不包含这些业务数据。公司抬头和税号默认为空，用户需要主动填写。

## 为什么自己的电脑可能显示旧设置

浏览器根据协议、主机和端口区分本地存储。同一个浏览器访问同一个本机地址，可以读取以前保存的设置，即使后端来自新复制的 exe。这些设置位于本机浏览器中，不能据此认定它们被打入 exe。

v0.4.1 将便携版默认端口改为 8766，使用 `fapiao-desktop-` 设置键；源码版继续使用 8765 及原有设置键。便携版不读取源码版抬头和执行偏好，也不删除源码版设置；后续会正常记住用户主动填写的内容。

## 本机数据

便携版的数据库、副本、上传文件和报告位于 `%LOCALAPPDATA%\发票助手\`。复制 exe 不会复制此目录；删除 exe 也不会自动删除此目录。备份时需要保护其中的个人、公司和行程信息。

程序会尝试复制本机旧临时目录中的历史上传和报告并保留旧文件。这是本机兼容逻辑，不是内置数据。测试设置独立目录变量后，不会访问这些旧目录。

## 发布检查

- 从脱敏源码构建，检查源码、资源清单及包内列表。
- 确认没有真实公司、税号、个人姓名、原始发票、数据库和浏览器配置进入包。
- 使用独立数据目录和全新浏览器用户目录启动成品，确认首次打开的抬头与税号为空。
- 同一测试地址放入虚构的源码版旧设置，便携版仍应为空；用户主动保存后应可恢复。
- 用虚构 PDF 检查导入和预览，核对真实库的哈希及副本数量未变化。

扫描不能替代明确的资源收集边界。以后增加资源或设置文件时，需要继续执行以上检查。
